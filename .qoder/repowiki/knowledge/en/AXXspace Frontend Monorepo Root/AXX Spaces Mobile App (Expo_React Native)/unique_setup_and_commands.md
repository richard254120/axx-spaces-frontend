Development: `npm start` (Expo dev server), `npm run android` / `ios` / `web`. APK build: `npm run build:apk` (EAS preview) or `npm run build:android` (production). Resetting the project runs `node scripts/reset-project.js`. Android requires an emulator/device with Google Play Services for location/camera; `usesCleartextTraffic: true` is set so the app can reach non-HTTPS backends.
