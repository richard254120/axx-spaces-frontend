Entry point `main.jsx` bootstraps a React app with `BrowserRouter`, wrapping the tree in `AuthProvider` (`context/AuthContext.jsx`), `NotificationProvider` (`components/NotificationSystem.jsx`), and `ErrorBoundary`. `App.jsx` is the central route registry using `react-router-dom` `<Routes>/<Route>` and three layout functions — `PublicLayout` (Navbar + WhatsApp + download notifier), `DashboardLayout` (role-focused nav via `AccountLayout`), and `BareLayout` (auth-only pages). Route guards are centralized in `components/ProtectedRoute`, which enforces role-based access (`allowedRoles`) per route. State is split across: `context/AuthContext.jsx` for global auth (token/user persisted to `localStorage`, plus invisible guest auto-sign-in), feature-scoped state inside `features/accommodation/` (hooks + components + constants/styles re-exported from `index.js`), and page-level state in `pages/`. API calls go through a shared Axios instance in `api/api.js` that injects `Authorization: Bearer <token>` from `localStorage`; domain-specific modules live under `api/` (`accommodation.js`, `profile.js`, `reviews.js`). The `features/accommodation` sub-package is self-contained with its own `constants.js`, `styles.js`, `auth.js`, `hooks/`, and `components/`, exposing a curated barrel via `index.js`. UI styling uses a unified design system in `styles/theme.js` (COLORS, SPACING, BORDER_RADIUS, FONT_SIZES, button/input/card/page style objects) consumed by pages and components; Leaflet is used for maps. Third-party integrations: Google Analytics (`react-ga4`), Vercel Speed Insights, and WhatsApp floating chat.
