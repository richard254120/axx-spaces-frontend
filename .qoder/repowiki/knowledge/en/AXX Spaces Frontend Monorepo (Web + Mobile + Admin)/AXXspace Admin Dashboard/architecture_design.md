Single-page React app built with Create React App (react-scripts 5) and react-router-dom v7. Entry point `src/App.js` wraps `BrowserRouter` inside an `AuthProvider` from `src/context/AuthContext.js`, which persists `token`/`user` in `localStorage` and exposes `login/logout/updateUser`. All HTTP calls go through a single Axios instance in `src/api/api.js` that injects a Bearer token from localStorage via a request interceptor and logs requests/responses; the backend base URL is read from `REACT_APP_API_URL` (defaulting to the Render-hosted backend). Routing maps `/`, `/login`, `/reset-password/:token`, `/business/:id`, `/business/create`, and `/boost-management` to page components under `src/pages/`. The bulk of the UI lives in one large `AdminDashboard.jsx` component that drives a tabbed sidebar (`TabNavigation`) and delegates domain-specific panels to shared components under `src/components/` (BadgeManagement, BoostManagement, PaymentApprovals, NotificationPanel, QRGeneratorModal, WebsitePoster, StatsCard, etc.). State is local to components — there is no global store or Redux — and data fetching is done inline with `useEffect` hooks plus a 30-second polling interval for notifications. CSS is co-located per-component as `.css` modules alongside their JSX.
